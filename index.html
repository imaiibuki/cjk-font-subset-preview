Why this matters

CJK fonts contain thousands to tens of thousands of glyphs, so they are large (in our tests: Noto Sans JP variable 9.6 MB, Zen Maru Gothic 3.8 MB, M PLUS 1p 1.8 MB). Godot embeds the font in your exported project, so it directly inflates web (.pck / download size) and mobile builds. A game's script usually uses only part of those characters; a subset keeps only the glyphs you need.

This page only previews and creates a static subset from the text you give it. Text added later (player names, new translations, user input) needs its characters to be in the subset too, or they will show as missing glyphs.

Only subset fonts whose license allows modification/subsetting (e.g. SIL OFL). OFL fonts with Reserved Font Names may require renaming.
